\# STAR Protocol (\`star-protocol\`) &gt; \*\*Story-Trace-Assert-Receipt (STAR)\*\* — A local, zero-cost verification harness and AST Merkle DAG receipt generator for autonomous agent execution. ## Key Features - \*\*Zero-Cost Verification\*\*: Runs 100% locally on developer hardware with zero cloud egress. - \*\*AST Merkle Receipts\*\*: Computes deterministic JCS SHA-256 tree roots and Ed25519 signatures to freeze baseline code behavior. - \*\*Zero-Delta Conservation Accounting\*\*: Ensures every execution row is deterministically classified (\`confirmed\`, \`unknown\`, \`conflict-held\`, \`malformed\`). - \*\*Human-in-the-Loop Gates\*\*: Prevents silent execution drift and compaction cliff decay. ## License Licensed under the [Apache License, Version 2.0](LICENSE)
